차량용 UDS Fuzzer 개발

2025

WhiteHat School 3기 · 팀 프로젝트

Audi A5 실차 환경에서 CAN·UDS 통신을 분석하고, DTC와 Expected Response로 이상 수준을 분류하는 퍼저를 개발했습니다.

대상
Audi A5 실차 환경
기여
UDS Fuzzer 개발, CAN 데이터 분석, DTC 기반 Fail Detection 단계 측정의 핵심 아이디어 제시
기술
Python, python-can, can-isotp, CAN, UDS
프로젝트 설명

Audi A5 실차 환경에서 진단 요청과 응답을 관찰해 ECU별 UDS ID와 지원 서비스를 매핑하고, 이를 바탕으로 테스트 입력을 구성했습니다. 단순한 응답 유무 대신 테스트 전후 DTC 변화와 Expected Response 수신 여부를 함께 확인해 이상을 4단계 Fail Level로 분류했습니다.

저는 UDS Fuzzer 개발과 CAN 데이터 분석을 맡았고, DTC를 활용해 Fail Detection 단계를 측정하는 핵심 아이디어를 제시했습니다. 팀 실험에서는 약 3만 건의 테스트케이스를 실행해 602건의 Fail을 확인했고, Level 2·3 재현 실험에서 95% 이상의 재현율을 기록했습니다. TARA를 통해 차량의 위협과 위험도도 검토했습니다.
